# Silence Web Project – Website vozidel Silence

Silence Web Project – Website vozidel Silence
Webový projekt představující elektronická vozidla značky Silence – inovativní řešení pro čistou městskou mobilitu.

## Obsah projektu

- index.html – Domovská stránka s přehledem produktů
- o-nas.html – Historia, mise a hodnoty společnosti
- produkty.html – Katalog dostupných vozidel
- kontakty.html – Kontaktní informace a formulář
- s02-cargo.html – Detail produktu S02 Cargo (pracovní skútr)
- s02-personal.html – Detail produktu S02 Personal (osobní skútr)
- s04-cargo.html – Detail produktu S04 (nanocar cargo verze)
- s04-personal.html – Detail produktu S04 (nanocar osobní verze)

## Technologie

- HTML5 – Sémantická struktura
- CSS3 – Responsive design, moderní layouty (Grid, Flexbox)
- JavaScript – Interaktivní prvky (lightbox, menu, animace)
- Google Fonts – Typografie (Bebas Neue, DM Sans)
